# 📄 Generador de PDF con Tabla Numerada

Aplicación web construida con **Streamlit** que permite generar documentos PDF con una tabla numerada, ideal para llevar el control de procesos manuales, registros físicos o seguimiento de actividades.

🔗 Demo en línea:  
https://contador-procesos.streamlit.app/

---

## 🚀 Características

- Generación automática de PDF
- Tabla numerada lista para impresión
- Interfaz simple y rápida
- Uso sin necesidad de conocimientos técnicos
- Ideal para procesos manuales y control documental

---

## 🛠️ Tecnologías utilizadas

- Python
- Streamlit
- Librerías de generación de PDF

---

## 📄 ¿Para qué sirve?

Esta herramienta es útil para:

- Registro manual de procesos
- Control de actividades en campo
- Seguimiento de tareas
- Formularios impresos personalizados
- Sustitución de formatos físicos tradicionales
